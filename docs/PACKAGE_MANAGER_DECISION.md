## Chosen Package Manager

**npm** (Node Package Manager)

## Rationale

| Factor | Finding |
|--------|---------|
| Lockfile present | `package-lock.json` is tracked in git and was used in Phase 1 |
| Binary available | npm 10.7.0 is available under Node 20 |
| Scripts work | `npm install`, `npm run build`, `npm test` all execute under npm |
| Yarn availability | No working Yarn binary in this environment |
| Project scripts | `package.json` scripts are standard and work with npm |

Do NOT remove Yarn artifacts in this phase. They can be removed in a later phase after:

1. Confirming no CI/CD or deployment scripts depend on Yarn
2. Confirming no team members use Yarn locally
3. Obtaining explicit approval to remove alternative package-manager artifacts
